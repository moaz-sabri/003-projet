# ملف معلومات الشركة — `company.json`

هذا الملف الوحيد الذي يتحكم بصفحتي **الرئيسية** و**تواصل معنا**.
عدّله بعد الرفع، وستتغيّر الصفحتان فورًا. لا تحتاج لوحة إدارة ولا قاعدة بيانات.

> **مهم:** الملف داخل مسار الويب، فمن يستطيع قراءة الموقع يستطيع قراءته.
> لا تضع فيه أي بيانات خاصة (أرقام هوية، كلمات مرور، أسعار جملة).

---

## الصور

كل حقل صورة يقبل ثلاث صيغ:

| الصيغة | مثال | متى تستخدمها |
| --- | --- | --- |
| اسم ملف داخل `app/uploads/` | `"brand/logo.png"` | **الطريقة الاعتيادية.** ارفع الصورة إلى `app/uploads/` واكتب اسمها هنا. |
| رابط كامل | `"https://example.com/a.jpg"` | صورة مستضافة خارج الموقع |
| رابط `data:` | `"data:image/png;base64,..."` | نادر — للأيقونات الصغيرة فقط |

**كيف ترفع صورة:** لوحة الإدارة ← المنتجات والتصنيفات (الرفع منها)،
أو يدويًا: ضع الملف في `app/uploads/` باسم بسيط مثل `hero.jpg`.

حقل `logo` يقبل أيضًا الشعار المرفوع من **إعدادات العرض** — القيمة هنا تتقدّم عليه إن وُجدت.

## كل الحقول

### `brand` — الهوية

| الحقل | يظهر في |
| --- | --- |
| `name` | رأس الصفحة، الغلاف، بيانات SEO |
| `tagline` | سطر واحد تحت الاسم |
| `logo` | شعار في الرأس (56×56 مناسب) |
| `hero_image` | صورة كبيرة أعلى الصفحة الرئيسية (1920×900) |
| `cover_image` | صورة عريضة فوق الغلاف — اتركها فارغة إن لم يكن لديك غلاف |

### `about` — التعريف

| الحقل | ملاحظة |
| --- | --- |
| `summary` | سطران يظهران تحت الغلاف مباشرة. أهم سطر في الملف. |
| `story` | القصة الكاملة — يظهر كقسم مستقل. |
| `highlights` | من 3 إلى 4 نقاط: `{ "icon", "title", "text" }` |
| `gallery` | مصفوفة صور لمعرض أعمالك. |

### `home` — الصفحة الرئيسية (Landing)

كل ما هنا يمكن ضبطه من هذا الملف **أو** من «إعدادات العرض» في لوحة الإدارة.
القاعدة: القيمة الفارغة في الإعدادات تعني «اتبع هذا الملف»، لا «أخفِ».

| الحقل | القيم | ملاحظة |
| --- | --- | --- |
| `layout` | `classic` · `split` · `cover` · `spotlight` | شكل الغلاف |
| `height` | `compact` · `large` · `full` | ارتفاع الغلاف |
| `show_highlights` | `true` / `false` | نقاط التميّز |
| `show_sections` | `true` / `false` | الأقسام |
| `show_gallery` | `true` / `false` | معرض الصور |
| `show_stats` | `true` / `false` | الأرقام داخل الغلاف |
| `show_testimonials` | `true` / `false` | آراء الزبائن |
| `show_faq` | `true` / `false` | الأسئلة الشائعة |
| `show_cta` | `true` / `false` | شريط الدعوة |
| `show_contact` | `true` / `false` | التواصل السريع |

```json
"home": {
  "layout": "split",
  "height": "large",
  "hero": {
    "eyebrow": "منذ 2015",
    "title": "عنوان الغلاف",
    "text": "سطران يشرحان ما تقدّمه.",
    "primary_label": "تصفّح المنتجات",
    "primary_url": "/products",
    "secondary_label": "تواصل معنا",
    "secondary_url": "/#contact"
  },
  "stats": [{ "value": "+1200", "label": "زبون" }],
  "testimonials": [{ "quote": "خدمة ممتازة", "name": "سارة", "role": "زبونة" }],
  "faq": [{ "q": "هل التوصيل متاح؟", "a": "نعم، داخل المدينة." }],
  "testimonials_title": "قالوا عنّا",
  "faq_title": "أسئلة شائعة"
}
```

- `hero` الفارغ يعود تلقائيًا إلى اسم النشاط والنبذة وأزرار النمط.
- روابط الأزرار تقبل `https://…` أو مسارًا داخليًا مثل `/products`
  أو اسم صفحة مثل `products`، وترفض `javascript:`.

### `contact` — التواصل

`phone` · `whatsapp` · `email` · `instagram` · `facebook` · `telegram` · `tiktok` · `youtube` ·
`address` · `map_url` · `working_hours`

- للأرقام اكتبها عاديًا: `"03 123 456"` — يتحول تلقائيًا إلى رابط اتصال.
- لحساب إنستغرام اكتب `@name` أو `name` — يتحول إلى رابط.
- `working_hours`: مصفوفة على الشكل `{ "day": "السبت", "open": "09:00", "close": "21:00" }`.
  اترك `open` و`close` فارغين ليظهر مقابل اليوم «مغلق».

> `phone` و`instagram` يتشاركان نفس الحقل في **إعدادات العرض** بلوحة الإدارة.
> إذا تعارضت القيم، فالقيمة في هذا الملف هي الأحدث. فرّغها هنا لتعود إلى التحكم الكامل من الإعدادات.

### `sections` — أقسام الصفحة الرئيسية

مصفوفة كتل مرنة، كل كتلة:

```json
{
  "icon": "award",
  "title": "لماذا تختارنا؟",
  "body": "نص الفقرة. اتركه فارغًا إن أردت نقاطًا فقط.",
  "image": "work/1.jpg",
  "bullets": ["نقطة أولى", "نقطة ثانية"],
  "layout": "cards",
  "items": [
    { "icon": "shield", "title": "جودة مضمونة", "text": "فحص قبل التسليم." },
    { "icon": "truck", "title": "توصيل سريع", "text": "خلال 24 ساعة." }
  ],
  "flip": true
}
```

- `flip: true` ينقل الصورة إلى الجهة المقابلة في الشاشات الكبيرة.
- `layout`: `text` (نص وصورة جانبية) · `media` (صورة بارزة) · `cards` (بطاقات).
  اتركه فارغًا ليُختار `cards` تلقائيًا عند وجود `items`، وإلا `text`.
- `items`: بطاقات صغيرة داخل القسم، كل بطاقة `icon` و`title` و`text`.
- **الكتلة الفارغة لا تُعرض.** عنوان بلا نص ولا صورة ولا نقاط يُسقَط تلقائيًا،
  فلا تقلق إن تركت حقلًا فارغًا.

### `cta` — شريط الدعوة للإجراء

`title` · `text` · `button_label` · `button_url`
اترك `button_url` فارغًا ليتحوّل الزر إلى صفحة التواصل.

### `seo`

`title` · `description` · `keywords` — اتركها فارغة فيؤخذ اسم النشاط والوصف تلقائيًا.

### `footer`

`note` (سطر واحد) و `links` (مصفوفة `{ "label", "url" }`).

## القواعد التي تحميك من الأخطاء

القالب لا يتعطّل أبدًا بسبب هذا الملف:

| ما تكتبه | ما يحدث |
| --- | --- |
| خطأ في قوس JSON | الملف يُتجاهل بالكامل وتعمل الصفحة بإعدادات افتراضية |
| مفتاح غير معروف | يُتجاهل بصمت (بلا رسالة خطأ مزعجة) |
| نص طويل جدًا | يُقتطع عند الحد الآمن |
| رابط ليس `http(s)` ولا مسارًا داخليًا | يُسقط (يمنع روابط `javascript:`) |
| مسار صورة فيه `..` | يُسقط (يمنع الخروج من مجلد الرفع) |
| أيقونة غير مدرجة | تُسقط |

> **القاعدة الذهبية:** هذا الملف لا يضيف قدرات جديدة للقالب، بل **يملأ ما هو موجود فيه**.
> لإضافة قسم جديد: عدّل القالب لا الملف.
